## Defects Found

1. The ACA client used a disk name for a private registered image. Azure requires the disk ID. Fixed with a focused client/provider change and regression test (101 targeted tests passing).
2. A memory-resumed worker can remain on a stale WebSocket indefinitely. Infrastructure state is Running, but device heartbeat does not recover until a later prompt triggers disconnected-worker replacement.
3. Router rolling revisions can overlap and replay a durable event, producing duplicate agent output. Exactly one router revision remained after rollout.
4. Cold replacement/reopen preserves worktree state but can emit terminal `error` before `complete` and omit the requested final response.
5. Terminal worker teardown callback did not arrive; the documented 10-minute fallback cleaned resources correctly.
